# 🤖 Projeto Android

Projeto desenvolvido durante o **Curso de HTML5 e CSS3** do **Curso em Vídeo**, ministrado pelo professor **Gustavo Guanabara**.

O objetivo deste projeto foi aplicar os conhecimentos adquiridos ao longo do curso na criação de uma página moderna e responsiva sobre a história do sistema operacional **Android**, utilizando boas práticas de HTML5 e CSS3.

---

## 🚀 Demonstração

> *(https://eijhenyfer.github.io/android-page/))*

---

## ✨ Funcionalidades

* 📱 Layout totalmente responsivo
* 🎨 Design moderno utilizando CSS3
* 📝 Estrutura semântica com HTML5
* 🔤 Uso de fontes personalizadas
* 📹 Incorporação de vídeo do YouTube
* 📖 Conteúdo organizado e de fácil leitura
* 📋 Navegação simples e intuitiva
